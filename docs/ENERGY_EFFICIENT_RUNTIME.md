# Energy Efficient Runtime Guidance

## Purpose

The runtime can adapt creative workloads based on available device resources while preserving deterministic behavior.

## Energy profiles

- `eco`: minimize unnecessary rendering and animation work.
- `balanced`: default user experience with resource awareness.
- `performance`: prioritize responsiveness on capable hardware.

## Design principles

- Avoid unnecessary computation.
- Respect user accessibility preferences.
- Preserve provenance boundaries.
- Measure before optimizing.

## Future expansion

Future runtime telemetry should remain privacy-preserving and focus on aggregate efficiency signals.
