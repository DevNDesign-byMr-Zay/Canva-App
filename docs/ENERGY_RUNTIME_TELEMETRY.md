# Energy Runtime Telemetry

## Purpose

The creative runtime should measure efficiency signals without collecting unnecessary user data.

## Signals

- rendering workload class
- active power profile
- frame optimization decisions
- resource-saving actions

## Design Rules

- Prefer local calculations where possible.
- Do not collect personal content.
- Keep telemetry optional and transparent.
- Optimize before scaling compute.

## Future Extensions

- adaptive rendering budgets
- device-aware optimization
- sustainability reporting
